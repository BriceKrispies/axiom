Treasure Chest Pick

Nine chests. The prizes were placed before you arrived. Pick one and it opens.

Pick a chest

One ladder, top to bottom: webgpu → webgl2 → webgl1 → canvas2d → css3d → this plain form. The renderer is chosen by painting a test pattern on each rung and looking at the pixels that come back; add ?render=canvas2d (or any rung name) to force one. Every rung is optional, the chests are the same nine form buttons at all of them, and the answer is identical — the same POST /api/pick, decided by the same chance engine.
