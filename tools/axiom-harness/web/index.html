Hostile-environment harness

The game below is the real one, served from this origin with the real /api/pick behind it. The controls take capabilities away from it and the readout says which rung it landed on. Nothing here is mocked; the only thing the harness adds is denial.

Render rung

One ladder: webgpu → webgl2 → webgl1 → canvas2d → css3d → form. Cumulative: a rung denies every tier above it, so the name of the rung is the tier the page should land on. form is the served document and cannot be denied — it is what is left when everything above it is gone.

Cross-cuts

The things a locked-down browser does that are not about drawing.

No JavaScript

The sandbox keeps allow-forms allow-same-origin. Without allow-forms the POST is silently swallowed — the harness would delete the exact rung this rung exists to prove.

Cannot be enforced from this page

These are chosen when the browser is launched. A page cannot relaunch its own browser, so the harness will not pretend to apply them — it prints the command line instead. The Playwright suite does enforce them.
